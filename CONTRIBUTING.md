# Contributing

Open an issue with a concrete writing failure, the input, the output, and the expected improvement. Remove private information and get permission before sharing real correspondence. A small reproducible case is more useful than another universal banned-word rule.

For code changes, run `npm test`. For writing changes, compare the same model and task with and without the change, then describe the observed difference. Keep evaluation examples separate from examples used to tune the skill. See [benchmark protocol](docs/benchmark.md).
