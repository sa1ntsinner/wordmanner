# Security and private writing samples

Wordmanner stores imported samples in `~/.wordmanner/` by default. You can override the path with `WORDMANNER_HOME` or `--store`; the repository's `.wordmanner/` directory is ignored by git. `context` prints selected excerpts to standard output. Sending that output to an external model sends those excerpts to that model provider. Review samples before import and avoid importing messages written by someone else as your own voice.

Please report security issues privately through GitHub's security advisory flow once the repository is public. Do not put private writing samples, credentials, or exploits in a public issue.
